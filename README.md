## Open the project

1. Download and extract [WTP-Practice-Drawings.zip](WTP-Practice-Drawings.zip).
2. Open `WTP Projects.wdp` in AutoCAD Electrical. The supplied source folder identifies an AutoCAD Electrical 2020 workspace.
3. The archive includes the original `Symbols/` folder with 10 supporting DWG symbols. Remap library paths if your installation uses a different location.

The individual drawing files are also browsable in the repository root. GitHub does not render native DWG drawings; use AutoCAD or a compatible viewer to inspect them.
