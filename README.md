# AutoCAD Electrical Portfolio

A personal practice drawing portfolio covering control-panel architecture, power distribution and PLC output wiring.

| Project | Scope |
| :--- | :--- |
| [WTP Control Panel](WTP_Control_Panel/README.md) | Seven retained DWG sheets, a WDP project, and ten supporting symbols. |
